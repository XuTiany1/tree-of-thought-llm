
==================================
self.stops explained -> in the context of text.py
==================================

self.stops = ['\nPassage:\n', None]

self.stops is initialized as a list with two elements:
    1. '\nPassage:\n': A string indicating a specific stopping condition, i.e., 
    the text generation should halt when it encounters this substring.
    2. None: This indicates no specific stopping condition for that step, 
    allowing the generation to run to its natural endpoint or any other limit set by the model.


Usage of self.stops:

The self.stops list is used in the solve function to guide the stopping behavior 
of the text generation for each step. 
Specifically, it is passed to the get_samples function as the stop parameter. 
Here’s the relevant part from solve:
new_ys = [get_samples(task, 
                        x, 
                        y, 
                        args.n_generate_sample, 
                        prompt_sample=args.prompt_sample, 
                        stop=task.stops[step]) for y in ys]
    - For each step in the loop (up to task.steps, which is 2 here), 
    task.stops[step] provides the stopping condition for that step.
    - In the first step (step=0), stop will be set to '\nPassage:\n', 
    instructing the model to stop generating text when it reaches this substring.
    - In the second step (step=1), stop will be set to None, allowing generation 
    to proceed without an explicit stopping substring.
